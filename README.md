# 기출 지우개

공인중개사 1차(부동산학개론·민법) 기출 선지를 OX로 넘기며, 3번 연속 맞힌 선지는 저절로 지우고(날은 안 따지고, 맞힌 뒤 1시간이 지나야 다음 정답을 센다) 모르는 것만 남기는 폰 공부 앱. 오늘 탭 맨 위에 몇 회독째인지와 진행률이 뜬다.

- 주소: https://jjangguss-prog.github.io/gichul-jiugae/
- 폰에 설치: 아이폰은 Safari → 공유 → 홈 화면에 추가, 안드로이드는 Chrome → 메뉴 → 홈 화면에 추가
- 문제: 한국산업인력공단 큐넷 공개 기출문제(공공누리 출처표시). 정답: 큐넷 기출을 두 출처로 대조. 선지 근거: 이 앱을 위해 직접 작성.
- 오늘 탭 '▶ 5문제만': 해설까지 읽을 짬이 짧을 때 한 번에 5장(복습 2 + 새 카드 3)만 보고, 끝나면 '5문제 더'로 이어 간다.
- 기록은 기기 안(localStorage)에 저장된다. 설정 → 기기 간 동기화에 GitHub 토큰(gist 권한만)을 붙여 넣으면 내 계정의 비공개 gist(`jiugae-sync.json`)로 폰·PC·태블릿 기록이 이어진다. 카드·실전·개념서 섹션마다 더 늦게 바뀐 쪽을 쓰고, 하루 공부량은 기기별로 더한다. 토큰은 기록과 따로 그 기기에만 둔다.
- **개념** 탭: 27~36회 기출 지문으로 쓴 민법·학개론 개념서. 논점마다 핵심 한 줄, 개념, 대비표, 기출 지문 OX(답 가리기 가능), 출제자가 바꾸는 자리, 외우기 한 줄. 카드 뒷면의 📖 버튼으로 그 논점 섹션이 열리고, 섹션에서 그 논점 카드만 돌릴 수 있다.
- 해설은 개념어를 **굵게**, O/X를 가르는 결론을 형광 밑줄로 칠하고, 조문·판례 번호는 작은 회색으로 물려서 훑어 읽기 좋게 했다.
- 카드 뒷면에 그 선지만의 출제 의도(출제자가 이 문장으로 무엇을 시험하나, 어떤 착각을 노리나)가 뜬다. 앞면 회색은 출제자가 바꿀지 말지 고민하는 바로 그 자리(뒷면 삭선·형광펜 자리)만 칠한다.
- **지우기 시험**: 세 번째 정답(지워지는 순간)과 지운 카드 검사는 실전처럼 회색 칠 없이, 이 카드 문장 그대로이거나 논점 자리가 반대인 문장을 반반으로 낸다. 반대 문장은 다른 회차에 실제로 나온 쌍둥이 기출(118장, 같은 명제·같은 발문 맥락인 것만 손으로 골랐다)이 먼저고, 없으면 틀린 말 카드만 바로잡은 옳은 문장이다. 지어낸 틀린 문장은 내지 않는다. 자주 봐서 '이 문장은 O'로 외운 카드는 여기서 걸려 0부터 다시 돈다. 맞혔어도 답만 외운 것 같으면 뒷면의 '↩ 답만 외운 것 같아요'로 지우지 않고 남긴다. 현황 탭의 '지운 카드 다시 점검'으로 이미 지운 카드도 같은 시험으로 거를 수 있다(틀리면 되살아남). 예/아니오·계산 카드와 쌍둥이 기출이 없는 옳은 말 카드는 예전처럼 낸다.
- 임대차 지문은 같은 문장도 주택·상가·민법 중 어느 법이냐에 따라 정오가 갈려서(기간 2년 미만이면 주택은 2년, 상가는 1년), 패턴·개념서·또 나온 문장에서 지문 옆에 발문이 묻는 법(주택임대차보호법·상가건물 임대차보호법·민법 임대차)을 칩으로 붙였다. 발문에 법 이름이 없으면 X주택·X상가건물 같은 사례로 갈랐다(44문항, 지문 197개).
- **타시험** 탭: 2026년에 치러진 8개 시험(감정평가사·주택관리사·공인노무사·행정사·세무사·법원직 9급·법무사·변호사시험)의 민법·부동산학 기출 가운데 37회에 다시 나올 만한 논점. 민법 카드 34장(올해 시험 3곳 이상이면 1순위), 학개론 42장(감정평가사 37회 부동산학원론). 출제자가 바꿔 치는 자리를 회색으로 가린 채 줄을 눌러 확인하고, 펼치면 다른 시험이 실제로 바꿔 낸 틀린 꼴과 나온 시험·공인중개사 출제 회차·판례가 뜬다. 카드 안 줄을 다 눌러 보면 ✓(기기 간 동기화됨). 자료는 `tasihum.json`.
- **듣기**(내 목소리, AI 합성): ★패턴은 패턴마다, 타시험은 목록의 '🔊 이어 듣기'·카드의 '🔊 이 카드부터'·줄마다 ▶(형광펜 자리를 '빈칸'으로 읽고 잠깐 쉰 뒤 온전한 문장과 틀린 꼴), 또 나온 문장은 '🔊 듣기'·'🔊 틀린 것만'(429개 전부, 과목·회수 거르기 그대로), 개념의 외우기 모음은 '🔊 듣기'와 장·섹션마다 ▶(A·B급 외우기 한 줄). 아래 재생 막대 하나로 이어 듣고, 제목을 누르면 지금 듣는 화면으로 간다. 오디오는 따로 내릴 수 있게 전용 저장소(gichul-jiugae-audio)에 있다.
- 설정 → 화면에서 자동(폰 설정을 따름)·밝게·어둡게를 고른다. 기기마다 따로 둔다.
- 한글은 띄어쓰기 자리에서만 줄을 바꾼다(낱말 가운데서 끊기지 않게). 어두운 화면에서 결론 형광 밑줄은 앞면 형광펜처럼 밝은 노랑으로 칠한다.
